# 🍞 مخبز ريف المعادي - Full-Stack Bakery Website & Admin Dashboard

نظام متكامل لموقع مخبز "ريف المعادي" (المعادي، القاهرة، مصر) يشمل واجهة الزبائن العامة، ولوحة تحكم إدارية احترافية لمالك المخبز، مع خادم خلفي مبني باستخدام **Node.js** و **Express.js** وقاعدة بيانات **MongoDB**.

---

## 🌟 نظرة عامة على المشروع (Project Overview)

يتيح هذا النظام لمالك المخبز إدارة وتحديث كافة محتويات الموقع العام بشكل فوري ومستقل دون الحاجة لأي تعديل في الكود المصدري:
* **تحديث وتعديل الأسعار فورياً** مع دعم الأسعار الأساسية وأسعار الخصم/العروض بالجنيه المصري (EGP).
* **إدارة التوفر والكميات**: إمكانية تغيير حالة أي صنف إلى "نفد مؤقتاً" ليتعطل زر الطلب ويظهر تنبيه للزبائن، أو إخفاؤه تماماً.
* **إدارة المنتجات والأقسام**: إضافة أصناف جديدة، رفع الصور من الجهاز أو عبر روابط، وتعديل الأقسام وتصنيفاتها.
* **ربط واتساب فوري**: زر واتساب عام وأزرار مخصصة لكل صنف تقوم بإنشاء رسالة تلقائية مجهزة باسم الصنف وسعره الحالي.
* **لوحة تحكم إدارية آمنة**: محمية بنظام تشفير كلمات المرور (bcrypt) ورموز الدخول المشفرة (JWT) مع إحصائيات فورية للمخزون.

## ⚙️ متطلبات التشغيل (Prerequisites)

* **Node.js** (إصدار 18 أو أحدث)
* **npm** (مثبت تلقائياً مع Node.js)
* **MongoDB**:
  * قاعدة بيانات محلية (مثل MongoDB Community Server على المنفذ `27017`)
  * أو رابط سحابي من **MongoDB Atlas**
  * *ملاحظة*: في حال عدم توفر خادم MongoDB محلي في بيئة التطوير، يقوم النظام تلقائياً بتشغيل خادم ذاكرة مدمج (`MongoMemoryServer`) حتى يعمل المشروع فوراً وبدون تعقيد.

## 🚀 خطوات التثبيت والتشغيل (Quick Start)

### 1. تثبيت الحزم البرمجية (Install Dependencies)
افتح موجه الأوامر أو الطرفية داخل مجلد المشروع ونفذ:
```bash
npm install
```

### 2. ضبط متغيرات البيئة (Configure Environment Variables)
تأكد من وجود ملف `.env` في المجلد الرئيسي (تم إنشاؤه افتراضياً، ويمكنك تعديله):
```env
PORT=5000
NODE_ENV=development
MONGODB_URI=mongodb://localhost:27017/reef_maadi_bakery
JWT_SECRET=reef_maadi_secret_jwt_key_2026_secure_bakery_auth_token
JWT_EXPIRES_IN=7d
ADMIN_EMAIL=admin@reefmaadi.com
ADMIN_PASSWORD=admin123456
```

### 3. بذر البيانات وحساب المدير الافتراضي (Database Seeding)
يقوم الخادم تلقائياً عند أول تشغيل بفحص قاعدة البيانات وبذر الأصناف الـ 9 الافتراضية، والأقسام، وحساب الإدارة الأول.
وإذا أردت تنفيذ البذر يدوياً في أي وقت:
```bash
npm run seed
```

### 4. تشغيل الخادم والموقع (Run the Server)
لتشغيل الخادم في وضع التشغيل القياسي:
```bash
npm start
```
أو في وضع التطوير:
```bash
npm run dev
```

ستظهر في الطرفية رسالة التأكيد التالية:
```

🔑 مدير افتراضي:   admin@reefmaadi.com (كلمة السر: admin123456)
```

## 🛠️ دليل استخدام لوحة الإدارة (Owner's Guide)

### 1. تغيير سعر منتج فورياً (Price Management)
1. سجل الدخول إلى لوحة التحكم [http://localhost:5000/admin](http://localhost:5000/admin).
2. انتقل لتبويب **"إدارة المنتجات والأسعار"**.
3. أمام المنتج المراد تعديله، اضغط على زر العملات الذهبي **(تعديل السعر السريع)**.
4. أدخل السعر الجديد واضغط **"حفظ السعر الجديد"**.
5. افتح الموقع العام ستجد السعر الجديد ظهر فوراً للزبائن وفي رسائل الواتساب.

### 2. إضافة خصم أو عرض خاص (Discounts & Deals)
* افتح تعديل المنتج وضع "سعر الخصم".
* سيظهر في الموقع العام السعر القديم مشطوباً والسعر الجديد باللون البرتقالي المميز مع شارة "عرض خاص".

### 3. إدارة التوفر (Out of Stock Control)
* إذا نفد أحد المخبوزات خلال اليوم، اضغط على زر الحالة الأخضر **"متوفر"** في جدول المنتجات ليتحول فوراً إلى **"نفد"** باللون الأحمر.
* على الموقع العام، سيتم تعطيل زر الواتساب لهذا الصنف ويظهر مكانه زر رمادي: `نفد لليوم - سيتوفر غداً` مع شارة حمراء واضحة.

### 4. رفع صورة جديدة للمنتج (Image Upload)
* يمكنك إما اختيار **"رفع من الجهاز"** واختيار ملف صورة (JPG, PNG, WEBP) من حاسوبك أو هاتفك وسيتم حفظها على الخادم، أو اختيار **"رابط صورة خارجي"** ولصق رابط مباشر مع معاينة حية فورية.

## 📡 توثيق واجهات الـ RESTful APIs

### المصادقة (Authentication)
* `POST /api/auth/login`: تسجيل دخول المشرف واستلام رمز الـ JWT.
* `GET /api/auth/me`: جلب بيانات المشرف المسجل حالياً (يتطلب `Authorization: Bearer <token>`).
* `POST /api/auth/change-password`: تغيير كلمة المرور.

### الأقسام (Categories)
* `GET /api/categories`: جلب الأقسام المعروضة للجمهور.
* `GET /api/categories?admin=true`: جلب جميع الأقسام مع عدد منتجات كل قسم (للإدارة).
* `POST /api/categories`: إضافة قسم جديد (يتطلب تصريح مدير).
* `PUT /api/categories/:id`: تعديل بيانات قسم (يتطلب تصريح مدير).
* `DELETE /api/categories/:id`: حذف قسم بشرط عدم وجود منتجات تابعة له (يتطلب تصريح مدير).

### المنتجات (Products)
* `GET /api/products`: جلب المخبوزات المعروضة على الموقع مع إمكانية التصفية بحسب القسم `?category=slug` أو البحث `?search=term`.
* `GET /api/products/admin`: جلب كل المنتجات متضمنة المخفية والنافذة للمشرف.
* `GET /api/products/:id`: تفاصيل صنف معين.
* `POST /api/products`: إضافة منتج جديد (يتطلب تصريح مدير).
* `PUT /api/products/:id`: تعديل منتج أو سعره (يتطلب تصريح مدير).
* `PATCH /api/products/:id/toggle-status`: تبديل حالة التوفر `isAvailable` أو الظهور `isActive` بضغطة زر.
* `DELETE /api/products/:id`: حذف منتج نهائياً من قاعدة البيانات.

### الوسائط والإحصائيات (Upload & Statistics)
* `POST /api/upload`: رفع ملف صورة عبر `multipart/form-data` (حقل `image`).
* `GET /api/stats/overview`: إحصائيات لوحة التحكم (إجمالي الأصناف، المتوفر، النافذ، الأقسام، وآخر المنتجات المحدثة).
* `GET /api/health`: فحص حالة تشغيل الخادم.
